# Tec petshop
### Documentação do projeto ⚙
### Projeto:
Esse projeto está sendo elaborado para que gerencie o atendimento e agendamento em uma clinica veterinária. Criando duas interfaces, uma para usuário e seu pet e outra para o médico que irá atender o pet.

## Stacks
- Laravel
- Tailwind
- Mysql
- jetstream
- fontawesome
